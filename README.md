## Customising

- **Fonts, text brightness, sizes and watermark strength:** edit the
  `SETTINGS` block at the top of `assets/css/site.css`.
- **Moving background on a page:** set `watermark:` in the page's front
  matter to `sandpile`, `pattern`, `powerlaw`, `noise`, `modular` or `none`.
  The animations live in `assets/js/watermark.js`.
